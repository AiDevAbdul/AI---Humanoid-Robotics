# ROS 2 کا تعارف

م module 1: روبوٹک نروس سسٹم کے پہلے باب میں خوش آمدید۔ اس باب میں، آپ روبوٹک ایپلی کیشنز کے لیے کمیونیکیشن فریم ورک کے طور پر کام کرنے والے روبوٹ آپریٹنگ سسٹم 2 (ROS 2) کے بنیادیات سیکھیں گے۔

## ROS 2 کیا ہے؟

ROS 2 روبوٹک سافٹ ویئر لکھنے کے لیے ایک لچکدار فریم ورک ہے۔ یہ اوزاروں، لائبریریز، اور رسموں کا ایک مجموعہ ہے جو پیچیدہ اور مضبوط روبوٹک ایپلی کیشنز بنانے کے کام کو آسان بنانے کا مقصد رکھتا ہے۔

## اہم تصورات

- **Nodes**: عمل کے عمل جو کمپیوٹیشن کرتے ہیں
- **Topics**: نامزد بسز جن کے ذریعے نوڈس پیغامات کا تبادلہ کرتے ہیں
- **Services**: ہم آہنگ درخواست/جواب کمیونیکیشن پیٹرن
- **Actions**: غیر ہم آہنگ، ہدف کے مرکوز کمیونیکیشن پیٹرن

## انٹرایکٹو عناصر

یہ ٹیکسٹ بک آپ کو سیکھنے میں مدد کے لیے انٹرایکٹو عناصر پر مشتمل ہے:

1. **کوڈ پلے گراؤنڈ**: ہمارے ایمبیڈڈ ٹرمنل میں ROS 2 کمانڈز آزمائیں
2. **3D وژولائزیشن**: 3D روبوٹ ماڈلز کے ساتھ ROS 2 کے تصورات کو عمل میں دیکھیں
3. **کوئزز**: انٹرایکٹو کوئزز کے ساتھ اپنے علم کی جانچ کریں

ذیل میں پلے گراؤنڈ میں ایک سادہ ROS 2 کمانڈ چلانے کی کوشش کریں:

```bash
ros2 run turtlesim turtlesim_node
```

یہ turtlesim نوڈ کو لانچ کرے گا، جو ROS 2 کے تصورات سیکھنے کے لیے ایک سادہ سیمولیٹر فراہم کرتا ہے۔
